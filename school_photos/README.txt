SCHOOL PHOTOS — Recent Highlights carousel (Events page)
=========================================================
1. Copy photos (.jpg, .jpeg, .png, .gif, .webp) into this folder.
2. Double-click the update script:
     Mac:     update-photos.command   (first time: right-click > Open)
     Windows: update-photos.bat
3. Refresh the Events page. The carousel shows the photos in random order,
   about 5 seconds each.

The first time you run the script it also downloads the 6 photos from the
old PTA site into this folder. Delete any photo you don't want and run
the script again. To remove a photo, delete it and run the script.

Tip: landscape photos look best. Keep each photo under ~1 MB so the page loads quickly.
